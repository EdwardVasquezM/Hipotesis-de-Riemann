# La hipótesis de Riemann

Presentación educativa en HTML sobre la función zeta, el plano complejo y la hipótesis de Riemann. Pertenece al grupo **laboratorio / aprendizaje**; su visibilidad pública se conserva.

## Consultar

- [Presentación publicada](https://EdwardVasquezM.github.io/Hipotesis-de-Riemann/).
- Descarga el repositorio y abre `index.html`, manteniendo la carpeta `imagenes_X/`.
- Navega con **Anterior**, **Siguiente** o las flechas del teclado. **Cerrar** oculta la presentación; recarga la página para volver a verla.

Tailwind CSS y MathJax 3 se cargan desde servicios externos, por lo que se necesita conexión para disponer del formato completo y las fórmulas.

## Estructura

- `index.html`: presentación de 16 diapositivas.
- `imagenes_X/`: cinco imágenes PNG y una animación MP4.

## Alcance y reproducibilidad

El repositorio ofrece material de divulgación y visualizaciones; no incluye una demostración matemática ni el código generador de las imágenes. Para reproducirlas se necesitan las funciones utilizadas, dominio, resolución, precisión numérica, parámetros y herramientas originales.

Las ilustraciones no sustituyen una demostración. Verificar fuentes y fechas antes de reutilizar afirmaciones sobre el estado de la investigación.
